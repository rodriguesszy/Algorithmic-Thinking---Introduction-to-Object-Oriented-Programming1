# RentSmart — Sistema de Orçamento de Locação

Aplicação desenvolvida em Python utilizando Programação Orientada a Objetos (POO) para automatizar os orçamentos de locação da imobiliária **R.M Imóveis**.

## Funcionalidades
- Cálculo automatizado para Apartamentos, Casas e Estúdios.
- Aplicação dinâmica de adicionais (quartos, garagem, pacote de vagas).
- Aplicação de desconto de 5% para apartamentos sem crianças.
- Parcelamento da taxa contratual (R$ 2.000,00) em até 5x.
- Exportação da projeção financeira de 12 meses em formato `.csv`.

## Como executar
1. Certifique-se de ter o **Python 3.x** instalado.
2. Clone este repositório ou baixe o arquivo `rentsmart.py`.
3. No terminal, execute:
   ```bash
   python rentsmart.py
